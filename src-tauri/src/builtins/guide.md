# aglab 使用指南

aglab 是一台桌面端的 AI 工作台：聊天区是与模型的对话，模型可以调用内置工具读文件、执行命令、操作窗口、派出子智能体。这份指南按界面分区讲清每一处是干什么的。

## 设置分区地图（左下角「管理 → 设置」）

- **通用**：外观（主题、强调色、字号、缩放）、应用（关闭行为、开机自启、置顶）。
- **模型**：端点档案、模型池、模型路由、代理、用量。
- **Agent**：运行行为（权限档位、自动压缩、工具轮数上限）、决策层、子智能体。
- **扩展**：工具（12 个内置工具的逐条开关）、技能。
- **数据与统计**：本地存储（会话存 JSON 还是 SQLite）、记忆、导入其他 AI 应用、cc-switch 迁移。

## 模型连接

- **端点档案**：一套连接配置的快照——根地址（baseUrl）、线协议（`chat` = /chat/completions，`responses` = /responses，`anthropic` = /v1/messages；中转站常常只开其中一条）、模型名、思考程度、温度、max_tokens、上下文窗口、缓存选项。切换档案 = 整份连接域抄写到顶层。**密钥不进配置文件**，只存 Windows 凭据管理器，档案只记去哪读。
- **模型池**：把多张端点上的模型组成池子由调度器每一发挑一个。模式：关 / 智能调度（auto）/ 手动指定（pinned）/ 决策模型（decision）。调度策略有加权轮询、最少并发、加权随机、优先级转移（failover：永远用列表里第一个健康的成员，失败自动滑到下一个）。同一会话粘住上一次的成员保住端点缓存；连续失败 3 次的成员自动进冷却（30 秒起步逐次翻倍，上限 10 分钟），冷却结束自动归队。
- **模型路由**：按模型名改写请求——设置里选的模型命中规则时，这一发改发规则指定的端点档案与模型名。匹配支持精确与 `*` 结尾前缀。生效档位：点名（子智能体/编排/任务）> 模型池 > 路由表 > 设置直连。
- **代理**：绑定分三级（端点内按模型 → 端点 → 全局），支持 http 与 socks5。aglab 不读系统代理环境变量。绕过名单按域后缀匹配，本机回环恒直连。
- **用量**：按「实际发出的模型名」记账——路由改写之后记的是改写后的名字；有请求明细与花费。

## Agent 能力

- **权限档位**：ask（每次改动都问）/ auto（只在高风险时问）/ full（不再询问）。切入 full 要逐条看过风险说明并确认。档位放不开的底线：项目外写永远拒、自我毁灭形命令直接拒、逐工具开关与钩子仍然生效。
- **作业模式**：对话 / 规划 / 目标，在输入框下方那颗选择器上。一条会话一个，存在会话日志里——回溯到哪一支就带回那一支的模式。它与权限档位是两件事：档位问"这一下要不要点头"，模式问"这一支准不准动手"。
  - **规划**：只读研究。写文件、编辑、执行命令、打开程序、操作别的程序、读窗口控件、扩展（MCP）工具、派子智能体都会被执行侧当场拒掉，**这条与档位无关，换成完全访问也开不动**；读文件、搜内容、查网页、取技能照常。它交出一份方案之后，输入框上方才出现「批准并执行」——刚切进规划模式、或你又追问了一句的时候不会有那颗按钮，因为屏上此刻没有一份按这套规矩交出来的方案。
  - **目标**：给定一个目标后一轮一轮自己往下推，中间不回来问话，**做到它报完为止——没有轮次上限**。做完或卡住由模型调 `goal_report` 上报。要拦它只有两处：起目标时那个花费上限（按台账实花算，到顶就把目标落成"受阻"），或者输入框上的停止。上限留空 = 不设，那时只有它自己上报或你按停止能让它停。
  - 正在跑的那一轮不许切模式——要切先停。这是挡着的，不是忘了做。
- **内置工具 12 个**：list_files（浏览目录）、read_file（读取文件）、search_text（搜索内容）、write_file（写入文件）、edit_file（精确编辑）、run_command（执行命令）、web_fetch（读网页）、load_skill（取用技能）、list_windows（列出窗口）、inspect_window（读窗口控件）、computer_act（操作别的程序）、spawn_subagent（派出子智能体）。写文件与精确编辑有回滚快照（审查视图里看差异、可回退）；web_fetch 过出口域名名单与内网地址两道闸。
- **子智能体**：五个出厂角色（general-purpose、explore、reviewer、operator、distill）+ 用户自定义。聊天里模型用 spawn_subagent 派人，编排计划从花名册派工；每个子智能体有自己的工具白名单、权限与端点/模型覆盖。
- **决策层**：System 1（Laya 本地 / Jev 云端）看请求内容替模型池挑成员；挑不动退回调度器，绝不因为选不出就不干活。
- **记忆**：按本轮提法检索出的记忆段注入上下文；有整段不发的上限设置。

## 扩展

- **技能**：一份份 SKILL.md 操作清单。系统提示里只有清单（名字 + 描述，60 条上限），模型判断场景匹配后用 load_skill 取正文再照着做。来源：个人技能目录、插件自带、出厂内置。
- **插件**：目录容器，可同时带技能、MCP 服务器、钩子（命令与代理列出但不加载）。放进插件目录后点刷新。
- **MCP**：连外部服务的工具，一律按高风险处理，逐项确认。独立配置或写进插件的 .mcp.json。
- **钩子**：插件带的可执行脚本（PreToolUse 等），拿到本进程全部权限，所以要逐条看过内容确认才跑；内容改一个字节，确认自动作废。

## 任务与编排

- **计划任务**：定时或一次性自动运行的任务，跑在后台会话里，审批、用量与界面聊天同一套机制。
- **编排**：把一个目标拆成节点图并行跑，节点从子智能体花名册派人；全局并发上限管住所有计划加起来的路数。

## 其他

- **缓存**：端点声明支持 prompt_cache_key 时按账号×模型分域命中；缓存保温默认关（先花小钱赌命中），要过三道闸才真发。
- **会话**：粘贴截图直接进对话；发送后可插话（steering）、跟随轮自动继续；历史可重生成、编辑重发；存储可在 JSON 与 SQLite 间切换（附件元数据两边都带）。
