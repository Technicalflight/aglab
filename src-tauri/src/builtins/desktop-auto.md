# 桌面自动化

替用户操作这台机器上的其他程序：记事本、浏览器、资源管理器、任何有窗口的应用。工具链是 aglab 窗口三件套：**list_windows（列出窗口）→ inspect_window（读窗口控件）→ computer_act（合成鼠标键盘）**。做的就是你本人坐在这台机器前能做的事，每一步都不可撤销，所以节奏是"先探后动，每步验证"。

## 红线（先读这个）

- 标题里带口令、支付、凭据、钱包这类词的窗口，**读和动都直接被拒**——这一条连完全访问档也放不开，别尝试绕。
- 合成输入进的是拿到焦点的输入框：点错一个按钮可能就是发一封邮件、清一个字段。动作要小、要可验证，别连招。
- 用户没让你碰的应用不碰；任务做完就停，不留后台动作。

## 剧本结构（每一轮都这样走）

1. **定位**：list_windows 找目标窗口，记住确切标题。
2. **侦察**：inspect_window 读它的控件树——按钮、输入框、菜单都是带坐标的元素。**永远用侦察到的元素坐标，不要猜屏幕像素**。
3. **动作**：computer_act 一次只做一小步（点一个按钮 / 输入一段文字 / 按一组快捷键）。
4. **验证**：再 inspect 一次，确认状态真的变了（列表多了一行、文本框有了内容），再走下一步。界面响应有延迟，验证失败就等一拍重看，别盲发第二遍。

## 常见动作要领

- **打字**：先点目标输入框拿焦点，再输入。输入框是空的才对——追加前先确认里面原有内容该不该清。
- **快捷键**：Ctrl+S 保存、Ctrl+A 全选这类组合键比菜单点击稳；但保存对话框弹出后要重新侦察（新窗口）。
- **菜单**：先用键盘（Alt 呼出）或点击展开，inspect 会看到新出现的菜单项元素，再点。
- **文件对话框**：地址栏可以直接输完整路径回车，比逐级双击稳。
- **等待**：应用启动、页面加载都没有"好了"信号，靠 inspect 重读到的内容变化判断。

## 示例：把一段文字存成文件

1. list_windows → 找到「记事本 - 无标题」。
2. inspect → 记下文本编辑区坐标。
3. computer_act → 点击编辑区，输入文字。
4. computer_act → Ctrl+S；重新 inspect → 弹出「另存为」对话框。
5. 对话框地址栏输完整路径，回车；再 inspect 确认对话框消失。
6. 用 read_file 读回那个文件核对内容——文件系统是唯一可靠的对账面。

## 说在失败时

- 窗口读不到（标题打错、应用最小化）：先 list_windows 核对标题原文。
- 点了没反应：可能被 UAC、模态弹窗、或别的窗口抢了焦点——重新侦察，把看到的说给用户听。
- automation 是最后手段：能让模型直接读文件/跑命令完成的事（read_file、run_command），不要绕道模拟点击。
